# 本地 PDF 按阅读目的选择处理方式并就近归档

Agent 配合 WebSearch skill，按当前任务判断已有资料是否足够：轻量查阅可利用已有 Markdown 或本地阅读；需要完整阅读 PDF 或保存解析资料时，采用精准解析与归档。旧 Markdown 即使缺少来源或覆盖范围记录，也由 Agent 结合任务抽查，认为够用就原位复用，不因缺少记录而强制重解析。抽查结论不等于逐页验证。

需要新建解析包且未指定页码时，默认以整本为目标；显式指定页码时按所选范围处理，并明确其覆盖范围。完整阅读及归档使用 MinerU 标准精准解析，启用表格与公式识别并处理多栏版式。Agent 按单次预算分批接续，遇到额度不足或明确失败时报告原因并保留断点；中断后可继续原任务及缺失批次，避免重复提交。

新解析包保存在 PDF 旁边的同名解析目录，便于后续 Agent 查找，并随原资料一起迁移。包内保留 Markdown、图片等配套资源、原始 ZIP，以及原 PDF 对应关系、实际页码范围和任务状态。后续可从原 PDF 路径或解析包路径重新发现并读取结果；临时读取引用过期不影响解析包的长期保留。

本服务生成的解析包根据 PDF 内容及实际覆盖范围判断能否复用。原 PDF 内容更新时，在同一解析目录更新自动生成结果，不按内容另存长期历史版本。新结果成功保存后再替换旧结果；服务只管理自己生成并登记的文件，目录中的其他资料不删除。

上传前确认旁边目录可以保存解析包。目录不可写时先说明原因，等待用户指定可写位置，再继续上传和解析。

职责分工：skill 负责阅读目的判断、旧资料查找和抽查，以及预算内的接续调用；服务负责精准解析、解析包保存、自有结果的复用判断、任务续查与状态返回。此决策仅针对本地 PDF；现有远程 PDF 默认行为不在本次变更范围内。
