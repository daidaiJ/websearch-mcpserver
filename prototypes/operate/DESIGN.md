# WebSearch 控制中心设计规范

**状态：已冻结。** #31 已于 2026-11-27 经人工验收通过。运行时主题变量以 [tokens.css](tokens.css) 为准，控制台用途见 [PRODUCT.md](../../PRODUCT.md)。

## Overview

调用量与趋势是总览的第一阅读顺序。桌面将异常入口置于图旁，窄屏先显示趋势，再显示路由状态。搜索源页支持先按分类筛选，再比较延迟、额度或进入参数编辑。指标均带时间窗口。原型数据驻留本页内存。

## Colors

画布、导航和面板使用中性浅暗两套表面。浅色分割线取黑色 6% 透明度，暗色取白色 8%。系统模式响应操作系统外观变化。品牌绿、蓝、石墨各有浅暗值，只用于分类选中态、少量数据标记、额度进度、控件与焦点。品牌预设只覆盖强调色。以下四个语义 Token 随浅暗外观切换，各自保留文字或图例。

| 状态 | Token | 显示场景 |
| --- | --- | --- |
| 正常 | `--ok` 绿 | 健康状态、成功调用与成功折线 |
| 观测告警 | `--warn` 琥珀 | 最近时段的延迟或质量告警，附当前路由资格 |
| 路由冷却 | `--cooldown` 靛蓝 | 正在执行的路由暂停，带剩余时间和解除入口 |
| 严重异常、失败、危险操作 | `--danger` 红 | 严重异常源、失败折线、失败结果和最终重启确认按钮 |

严重程度描述已观测到的问题，能否参与路由由启用状态和实际冷却决定。历史 429 只表示该次尝试遭遇限流；靛蓝仅标记此刻正在执行的路由冷却。禁用源用中性色和文字标出，缺样本的槽位保持中性空格。

## Typography

**Phase 0 预览**使用上方记录的系统字体栈，方便直接打开本地文件。

**Phase 1 生产规范（#30）**：构建时将现代拉丁无衬线字体（如 Inter 或 Geist）与等宽字体（如 JetBrains Mono）的轻量 WOFF2 子集一起打入 Go 内嵌资源，合计预算约 100–250 KB。正文与代码分别以对应内嵌字体为首选，中文回退到 PingFang SC、Microsoft YaHei UI 等本机无衬线字体。指标、轴刻度、计数和额度启用 `font-variant-numeric: tabular-nums`。验收时断网打开页面，检查英文字形实际使用内嵌字体、中文正常回退、字体请求全部来自本地。Phase 1 不接受纯 Windows 默认字体栈或运行时从 CDN 取字。页面标题 25–32px，常规操作 14px，侧栏 13px，指标值用更大的半粗数字。工具标识保留等宽字体，源名称左对齐。中英文切换同步更新界面文字和文档语言。

## Layout

216px 侧栏承载监控、治理、系统三组导航。52px 粘性顶栏使用对称三列，保留居中的搜索入口。1280px 起，浅斜纹外轨收束宽屏内容。860px 及以下收起侧栏，导航由菜单按钮打开。窄屏允许操作条换行，图表保留日期轴。密度调整卡片内距、列表行高与页面间距。

## Elevation & Depth

常驻内容用 1px 线建立层级，浮层统一引用 `--layer-float-shadow`。搜索面板、齿轮偏好和吸底草稿栏通过内描边与层叠阴影从画布上抬起。命令面板、Diff 与保存确认使用磨砂背板，在对话结束前锁定背景交互。右侧 Inspector 使用轻半透明遮罩，保留清晰的左侧列表。桌面可直接点击另一行切换检视源，窄屏保留关闭入口。减少动态效果模式下直接呈现抽屉。

## Shapes

数据面板使用 15px 圆角，命令和偏好浮层使用 18px 圆角。分类、导航选中态和分段切换器使用药丸形状。图标以同一线宽绘制，状态点附文字，折线依靠图例、线型与悬浮读数共同辨识。

## Components

- **命令面板**：顶栏 Search、Ctrl+K 或 ⌘K 打开。按页面与搜索源分组过滤，方向键移动，Enter 打开，Esc 退出。
- **偏好浮层**：齿轮展开；外观、语言、密度与品牌点缀立即预览。暗色选中胶囊用微提亮的中性灰和 1px 内描边区分。齿轮通过键盘到达时显示焦点环，鼠标操作后恢复常规边框。刷新或重新打开文件后回到初始演示状态。
- **趋势图**：7 天与 14 天切换；指针或键盘读取单日成功、失败、缓存命中。缓存命中包含在成功中。
- **搜索源与 Inspector**：同一份源数据驱动卡片和紧凑列表。关键词与分类、状态可组合筛选。两种视图均保留近 20 次健康微条、今日尝试和成功率、主要失败类别及启用开关；仅有额度数据的源显示额度。抽屉按从早到晚展示 20 次调用，并分别列出最近 20 次和今日的失败构成，避免混淆统计窗口。解除冷却、刷新官方额度按源状态及类型展示，诊断试搜提供本地模拟入口。两种视图的开关和抽屉有效参数直接联动同一份草稿，编辑后可继续切换源。超时输入越界时，保留上一个有效草稿；关闭或切换前可返回修正，或明确放弃这次无效输入。
- **浮动草稿栏**：按变更字段数统计，跨页保留。浮栏出现时主内容与键盘滚动区域预留 100px 加设备底部安全区；末行控件可滚到浮栏上方。差异列出原值、新值，撤销清空草稿，保存并重启进入明确的模拟确认态。

## Do's and Don'ts

保留 Designeer 的纯净画布、细线、轻导航、搜索药丸和轻浮层。控制台用折线、指标、额度和左对齐的可比较列表占据主区域。反参照清单包括大图瀑布流、旧灰绿底、直角白板、粗绿 KPI 左边框、深绿导航选中块和全列居中的长表。
